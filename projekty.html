Generowanie ≠ weryfikacjaGeneration ≠ verification

Problem → decyzjaProblem → decision

Model językowy potrafi napisać przekonujący tekst — również wtedy, gdy nie ma racji. Dlatego wyszukiwanie BM25 wybiera fakty, a osobna warstwa Truth Lock kontroluje wynik.A language model can write convincing text even when it is wrong. BM25 retrieves facts, while a separate Truth Lock layer checks the result.

Co składa się na rozwiązanieWhat makes up the solution

  • Identyfikatory faktów zamiast swobodnego wymyślania historii.Fact identifiers rather than freely invented claims.
  • Edycja, historia oraz eksport PDF i DOCX.Editing, history and PDF / DOCX export.
Granice: wymagane logowanie i sprawdzenie dokumentu przez człowieka. Opcjonalne wyszukiwanie semantyczne w kodzie nie potwierdza jego aktywacji na produkcji.Limits: sign-in and human review are required. Optional semantic retrieval in the code does not confirm that it is enabled in production.
